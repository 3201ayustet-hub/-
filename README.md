# Poker Telop Maker

ポーカーショート動画向けの背景透過テロップPNG生成アプリです。

## 使い方

1. GitHubで新しいリポジトリを作る
2. このZIP内のファイルを全部アップロード
3. GitHub Pagesを有効化
   - Settings
   - Pages
   - Branch: `main`
   - Folder: `/root`
4. 表示されたURLを開く

## ファイル構成

- `index.html`
- `style.css`
- `app.js`

## 注意

プレビューの市松模様は確認用です。保存されるPNGは背景透過です。
