# Poker Short Material Maker v3

GitHub Pages用の静的Webアプリです。

## 機能

- テロップPNG生成
- プレイヤーHUD生成
  - 人の写真アップロード
  - 名前入力
  - ポジション選択
  - ハンド選択
  - アクション選択
  - 点数入力
- 相手HUD生成
  - グレー版
  - ポジション選択
  - アクション選択
  - 点数入力
  - 裏向きカード / カード選択
- 背景透過PNG保存
