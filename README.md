# v4 Poker Material Maker

GitHub Pages用の静的Webアプリです。

## 機能

- テロップ作成
  - アクションを最上位に配置
  - 自分/相手/お互い × アクションで自動演出
  - プルダウンから自動文章生成
  - 手入力欄で微調整
  - 文字切れ防止の自動縮小
  - 横長プレビュー

- プレイヤーHUD
  - 写真アップロード
  - 名前
  - ポジション
  - ハンドカードイラスト
  - アクション
  - 点数
  - プレイヤーテンプレ保存

- 相手HUD
  - グレー版
  - 裏向きカード/指定カード

- 作成キュー
  - 一時保存
  - 編集/削除/並び替え
  - ZIP一括PNG出力

## 設置方法

このZIPの中身をGitHub Pagesのリポジトリ直下へ上書きしてください。

- index.html
- style.css
- app.js
- README.md
